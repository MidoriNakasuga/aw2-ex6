Descrição
Sistema web educacional desenvolvido em PHP puro para demonstrar conceitos de autenticação, controle de acesso com sessões e filtros de dados.

Funcionalidades
Sistema de login com validação
Controle de acesso por sessão
Área restrita com listagem de produtos
Filtros de pesquisa por nome e categoria
Logout com encerramento de sessão
Requisitos
PHP 8.2 ou superior
Servidor web (pode usar o servidor embutido do PHP)
Como Executar
Extraia os arquivos em uma pasta
Abra o terminal na pasta do projeto
Execute o comando: php -S localhost:5000
Acesse no navegador: http://localhost:5000/login.php
